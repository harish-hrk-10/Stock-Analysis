# 📈 EDA-Stock-Analysis

An exploratory data analysis (EDA) project focused on analyzing stock market data to uncover trends, volatility, and potential correlations. This repository contains the Jupyter Notebook (`Stock_analysis.ipynb`) where the analysis is performed.

## 📋 Overview

This project performs a comprehensive Exploratory Data Analysis on stock price data. The goal is to visualize key metrics, understand data distribution, and identify patterns that could inform investment strategies or further machine learning modeling.

### 🔍 Key Objectives

* **Data Cleaning**: Handling missing values and formatting dates.
* **Visualization**: Creating interactive charts for price movements and volume.
* **Statistical Analysis**: Calculating returns, volatility, and moving averages.
* **Correlation**: Identifying relationships between different stocks or metrics.
